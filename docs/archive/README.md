# docs/archive/ — 역사 기록

여기의 문서는 **정본이 아니다**. 날짜가 박힌 스프린트/감사/폐기 계획의 스냅샷이며, 수치와 우선순위는 작성 시점의 것이다.

- 현재 수치는 [`../generated/STATUS.md`](../generated/STATUS.md), 현재 상태는 [`../HANDOFF.md`](../HANDOFF.md), 우선순위는 [`../ROADMAP.md`](../ROADMAP.md)를 읽어라.
- 새 역사 기록은 이 디렉터리에만 추가한다. 루트 `docs/`에 `FINAL_*`/`SPRINT_*` 문서를 새로 만들지 않는다.
- 파일: `AUTOMATION_LOG.md`, `SPRINT_2026-11-12.md`, `FINAL_REPORT.md`, `FINAL_CHECKPOINT.md`, `MASTER_PLAN.md`, `NEXT_PROMPT.md`, `EVALUATION.md`, `DIVINE_MOVE.md`, `STROKE_RESEARCH.md`.
