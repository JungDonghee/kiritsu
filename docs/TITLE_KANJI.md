# TITLE KANJI — 타이틀 한자(規律) 단독 규격서

> **이 파일을 먼저 읽지 않고 타이틀 한자를 만지지 마라.** v1·v2의 실수를
> 이 문서로 체계화한다. 현재 구현은 **v3(리본 리빌)**.

## 1. 자산 출처 (단일 진실)

| 항목 | 값 |
|---|---|
| 글자형 원본 | **`public/kanji/ou-guilv-tight.svg`** — 구양순체(Yuji Boku, OFL 1.1) |
| viewBox | `0 0 600 300` |
| fill | `#f2d8c9` (크림색 — 타이틀 전용) |
| 글자 그룹 | 規 `translate(-0.22,31.78) scale(0.23454)` / 律 `translate(312.44,-1.80) scale(0.32230)` |

**금지**: `kanji.ts`의 옛 `KANJI_KIRITSU_SVG`(viewBox 218×109, 분홍 그라디언트)는
타이틀에 쓰지 않는다 — 같은 Yuji Boku라도 변형·색·비율이 달라 원본 글자형이
사라진다. 타이틀 글자는 **오직 `ou-guilv-tight.svg` 하나**.

## 2. 애니메이션 원칙 (v3 = 붓 리본 리빌)

- **절대 금지**: 획이 "팡" 나타나는 페이드/팝. opacity만 바꾸는 연출 금지.
- **v1 실수**: 다른 변형 글자 사용 + 페이드. **v2 실수**: clipPath 안의 CSS
  `stroke-dashoffset` 애니메이션이 실제로 클립을 갱신하지 않아 얇은 레이저 선만
  그려지다가 마지막 settle 페이드로 글자 전체가 튀어나왔다(사용자 지적).
- **v3 구현(현재)**: `src/ui/kanji.ts`가 글자를 오프스크린 캔버스에 채워 잉크
  마스크를 만들고, 스켈레톤 점을 잉크 무게중심으로 다단계 스냅해 **획별 정확한
  중심선·두께**를 구한다. 그 위에 닫힌 **테이퍼 붓 리본**(가변 폭, 둥근 캡,
  ㆍ丿 테이퍼)을 만들고, rAF로 clipPath를 직접 갱신하며 앞에서부터 잉크를
  드러낸다. **CSS 클립 애니메이션은 쓰지 않는다.**
  - 획이 끝나면 그 획의 리본이 0.26s 동안 살짝 부풀어(잉크 번짐) 가장자리를
    채운다. 마지막 획 뒤에는 전체 리본을 0.46s 더 부풀린 뒤 clip을 제거해
    **최종 글자형 100%**를 보장한다.
  - 레이저 팁은 `.kt-laser-head`(radial glow)와 `.kts-tip`(중심선)이 담당하고,
    획이 바뀔 때 사라졌다 나타나며 이동한다(획 사이 펜 리프트).
  - 타이밍: 시작 0.62s, 획당 0.07~0.185s(길이 비례), 획 간 0.032s, 規 뒤
    0.12s 숨 고르기. 총 쓰기 ≈ 4.1~4.5s. 캡션·태그·PRESS는 JS가 `--kt-end`
    변수로 실제 종료 시각에 맞춘다.
  - `--kt-end`는 `.kt-screen`에 JS가 설정하고 CSS는 `calc(var(--kt-end, 4.4s)+…)`
    로 지연을 잡는다. **`.kt-screen`에 `--kt-end` 기본값을 다시 선언하지 말 것**
    (상속을 덮어써 타이밍이 어긋난다).
- **단일 파일 빌드**: `tools/inline.mjs`가 `./kanji/ou-guilv-tight.svg`를
  data URI로 인라인한다. 이때 **좌표 소수점을 정수로 반올림하고 태그 공백을
  줄여** 단일 파일을 경량화한다(원본 SVG 파일은 불변, glyph 단위 오차는 표시
  불가 수준). 같은 경로 문자열을 코드에 중복해서 쓰지 말 것(중복 인라인 →
  번들 예산 초과).
- `prefers-reduced-motion`: 즉시 전체 표시. `crt-off`: 팁/레이저 색만 흰색.

## 3. 실수 방지 체크리스트

1. 글자형은 `ou-guilv-tight.svg`에서만 (다른 파일·다른 변형 금지).
2. 획 연출은 실제 잉크가 드러나는 그리기여야 한다(fade/opacity 팝 금지).
3. **clipPath 자식의 CSS 애니메이션에 의존하지 말 것** — v2가 이 함정에 빠졌다.
   클립을 바꿔야 하면 rAF에서 attribute를 직접 갱신한다.
4. `node tools/title-check.mjs` 통과: 20 리본 · `data-state=done` · clip 제거 ·
   tip/헤드 제거 · 캡션/태그/PRESS 노출 · Esc 내비 · reduced-motion 즉시 완료 ·
   콘솔 에러 0 · 인트로 FPS ≥18.
5. `npm run budget` 그린(단일 파일 420KB/140KB — 인라인 중복 주의).
6. `npm run verify` 그린.
7. **Esc**: 타이틀에서 무시, 지도에서 타이틀 복귀. 전역에서 Esc는
   `preventDefault`(PWA 앱 종료 방지 — 사용자 지적). 건드리지 말 것.
8. 이 문서·HANDOFF §0k에 변경 기록.
