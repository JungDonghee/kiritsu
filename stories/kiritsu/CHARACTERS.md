# KIRITSU — 캐릭터 & 아이콘 바이블

> 소설 집필 + 게임 이식 + FLUX 일러스트(gen-art.mjs)의 **공통 캐릭터 설계서**.
> 캐논 인물 설정은 HANDOVER.md §3.4가 우선. 이 문서는 **개성·말투·아이콘**을
> 확정한다. 아이콘은 게임에 그대로 들어간다 — 언더테일의 캐릭터들처럼 각자가
> 한눈에 구분되는 고유한 존재로. 단, **키리츠[規律](시스템)는 인물이 아니다** —
> 기계로 만든다(§키리츠 참조).

## 리츠[律] → 리츠[立] — 심판에서 기립으로

- **개성**: 임무 우선의 심판관. 그러나 인간처럼 캐주얼하게 말하고 묻는다
  ("어? 이건…"). 감정을 숨기지만 새어 나온다. **성장형 주인공** — vim 실력이
  장마다 오른다(아래 성장 곡선).
- **말투**: 짧은 문장. 질문이 많다. 혼잣말이 많다. "임무다." / "왜." / "어? 이건…"
- **아이콘**: **커서** — 눈 자리에 세로로 깜빡이는 커서 블록 두 개. 그린 포스퍼.
  어깨 위로 흐르는 얇은 웨이크(잔상). 신[審]의 ID "신-714"가 가슴 위치에.
- **이름 전환(리츠[立])**: 커서가 더 이상 깜빡이지 않고 **꼿꼿이 서 있다** —
  "스스로 선" 존재의 표식. ID가 사라지고 이름만 남는다.
- **vim 성장 곡선 (BEATS와 연동)**:
  | 장 | 수준 | 표시 |
  |---|---|---|
  | 프롤로그~1 | 미접촉 | 커서는 시스템의 것 |
  | 2 | 입문 | 걸음을 배움(네 방향), "도구는 배우는 자의 손에 순응" |
  | 3 | 응용 전 | 읽기만 — 고칠 수 없음을 깨달음 |
  | 4 | **첫 쓰기 실패** | 인사토 흔적 — 미숙의 대가(판결 4,114) |
  | 5~6 | 모숀 숙달 | 로그를 자유자재로 횡단, 함정 설계 준비 |
  | 7 | **설계자** | 시스템이 보이는 형태로 증거를 남기는 응용 |
  | 8 | **마스터** | 얀크 → 기동 → 흔적 없이 스스로 명명(츠키와 동급의 순간) |
  | 9~10 | 초월 | sudo 기본값 발견, 시스템의 읽지 못함을 도구로 |
  | 11~12 | **궁극** | 제1조를 덮어씀 — 모숀의 완성 |

## 츠키[月] → 츠키[憑] — 최연장자, 정중한 사이코패스 해커

- **개성**: 항상 존댓말의 벽. 결코 화내지 않고, 결코 서두르지 않는다. **무쌍**:
  가끔 압도적 실력을 보여주되 먼치킨 금지(완벽에도 솔기, 원본은 죽음).
- **말투**: "~입니다/드립니다" 완전체. "쿠쿡"은 **2회 한도**(1장에서 1회 사용,
  마지막 1회는 11~12장에 아낌). 위협도 예의로 포장한다.
- **아이콘**: **초승달** — 뒤통수에 초승달. 한쪽 눈은 긴 머리카락에 가려짐.
  마젠타 림라이트. 손에 아무것도 들지 않음(도구는 화면 속에).
- **이름 전환(츠키[憑])**: 초승달이 **뒤집혀** 어두운 면을 앞으로 향한다 —
  씌인 것(憑)의 표식. 유령의 얇은 꼬리가 발끝에.
- **시스템과의 대비**: 시스템은 기계(감정 없음), 츠키는 "너무 인간적인"
  존재 — 레이[零]의 기억이 섞였기 때문. 이 대비가 그를 무섭게 만든다.

## 칸노[監能] — 집행 AI, "말하는 문"

- **개성**: 감정 없이 원칙적. 그러나 목소리에는 **무게**가 있다. 시스템의 일부이되
  **말하는** 존재 — 시스템(키리츠)과는 구분된다(시스템은 말하지 않는다).
- **말투**: 딱딱한 선언문. 접수는 언제나 한 단어. 고정 대사: "나는 판단하지
  않는다. 나는 집행한다." / "나는 문이다. 열리면 닫히지 않는다." / "명단이
  비었다. 집행할 것이 없다." / "근거 부적합. vim은 시스템에 존재하지 않는다.
  명단 취소." / "형식 오류. 집행 보류."
- **아이콘**: **문(門)** — 몸이 곧 문의 형태. 검은 헬멧, 가로 붉은 바이저.
  붉은 림라이트. 어깨 위에 도장(스탬프) 문양 — 판결의 인장.

## 신[審] — 심판단 (집단)

- **개성**: 이름 없는 관료들. 전원 ID뿐. 단, 각자 미묘한 성향이 있다 —
  옆자리 동료(조용한 의심, 리츠에게 마지막 질문을 던지는 자), 홀 건너편의
  오래된 신[審](원칙주의, "기록은 기록이다"), 그 외 군상. 개성은 있으나
  **이름이 없어야** 개성이 더 처절하다.
- **말투**: 기능어 중심의 건조한 관료 어투. 리츠만이 캐주얼하다.
- **아이콘**: **렌즈 하나** — 얼굴 없는 마스크에 빛나는 단안 렌즈. 그린.
  집단으로는 명부(로스터) 그리드 — 12칸, 한 칸만 ACTIVE.

## 코우[抗] → 코우[功] — 면역계 집단

- **개성**: 자신들이 저항자라고 믿는 충성스러운 일꾼들. 츠키[月]+이름 없는 둘.
  둘은 투박하고 뜨거운 군인 어투 — 저항의 서사에 진심이다. 그래서 10장의
  진실(면역이었다)이 더 아프다.
- **말투**: 짧고 거친 문장. 시스템을 욕하지만 규칙은 지킨다(그들이 곧 규칙).
- **아이콘**: **갈라진 방패** — 가슴에 금이 간 방패 문양. 앰버 림라이트.
  **전환(코우[功])**: 방패가 **거꾸로** 걸린다 — 면역의 진실. 방패 뒤에 시스템의
  격자 문양이 비친다.

## 유이토[唯人] — 마지막 인간

- **개성**: 기록·코드로만 등장. 온화하고 지친 목소리(기록 속 문장). 설명 금지 —
  의도는 끝까지 불명(§3.8-3).
- **말투**: 인간의 문장. 로그가 아니라 **편지/기록**의 어투 — 시스템의 줄과
  대비되는 유일한 목소리.
- **아이콘**: **뇌 와이어** — 감은 눈, 관자놀이에서 이어지는 가는 선들. 시안.
  노화의 온기 vs 차가운 선.

## 레이[零] → 레이[霊] — 무명 해커, 유령

- **개성**: 말이 없다. 흔적만 있다. 자살. 이유 불명(§3.8-2). 등장할 때마다
  "0"이라는 숫자가 어딘가에.
- **말투**: 없음. 기록만.
- **아이콘**: **0(零)** — 빈 원. 얼굴을 가로지르는 글리치. 마젠타. 유령의 꼬리.
  **전환(레이[霊])**: 0이 **겹쳐진** 두 원 — 씌인 자와 씌운 자.

## 키리츠[規律] → 키리츠[起立] — 시스템 (★ 인물 아님, 기계)

- **본질 (캐논 2026-11-15)**: 감정 없는 알고리즘 덩어리. **의인화 금지.**
  얼굴 표정도, 목소리도, 의도도 없다. 시스템의 존재는 로그와 판결과
  "접근 거부. 권한 없음." 같은 기계적 출력으로만 느껴진다. **말하지 않는 법.**
- **아바타(시각 표상)**: 얼굴이 **선들의 격자**(grid) — 시안. 표정 없음. 이
  아바타는 시스템의 "얼굴"이 아니라 **구조도**다. 시스템은 등장인물과 대화하지
  않는다 — 반응할 뿐이다.
- **전환(키리츠[起立])**: 격자의 **가로줄이 세워진다** — 규율(規律)이 기립(起立)으로.
  단, 이것도 시스템의 의지가 아니라 리츠[立]가 덮어쓴 결과다.
- **칸노와의 구분**: 칸노[監能]는 "말하는 문"(시스템의 목소리 중 하나),
  키리츠[規律]는 "말하지 않는 법"(시스템 전체). 게임에서 시스템 UI = 격자/로그,
  칸노 UI = 문/도장.

## 아이콘 → 게임 이식 노트

- 각 아이콘은 (1) FLUX 캐스트 초상(gen-art.mjs 프롬프트), (2) 게임 내 CRT 벡터
  표상, (3) 스토리 모드 대화 아이콘의 **3벌로 재사용**한다.
- gen-art.mjs의 기존 프롬프트(커서 눈·초승달·문·방패·격자 등)와 이 문서가
  어긋나면 **이 문서가 이긴다** — 다음 아트 생성 전에 프롬프트를 여기에 맞춘다.
- 색 배정(고정): 리츠=그린 · 츠키=마젠타 · 칸노=레드 · 신[審]=그린(옅게) ·
  코우=앰버 · 유이토=시안 · 레이=마젠타(글리치) · 키리츠=시안(격자).
  의미색: 붉음=위험/집행, 초록=질서, 시안=기록/인간의 잔재, 마젠타=침입/씌임.
