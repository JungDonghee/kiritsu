# KIRITSU — 소설 → 게임 이식 매핑 설계 (STORY TO GAME)

> 게임: 10층(floor) · 51 스테이지 · 88 그리무아 명령 · TRIALS 무한모드.
> 소설: 프롤로그+12장(약 73,000자). 이 문서는 **소설의 어느 부분이 게임의
> 어느 레이어가 되는지**를 정한다. 실제 문구 이식은 소설 확정(사용자 피드백
> 반영) 후이며, 게임의 목소리는 영어(한국어는 `Localized.ko` 번역)다.

## 0. 원칙 (AGENTS.md · STORY_BIBLE 준수)

- 게임은 소설 전체를 표시하지 않는다. 소설은 **서사의 공급원**이고, 게임은
  층별 **에피그래프(2~4줄) + 스테이지 브리프(1~3문장) + 인터루드(250~600단어)
  + 코덱스**만 소비한다.
- 브리프는 "수리할 로그 조각"처럼 **코드·로그 중심의 간결한 해커 터미널
  어조**여야 한다(시 비슷한 판타지 문체 금지).
- 캐논 불변식: 판결 번호 4,112~4,116 · 이름[한자] · 시스템=기계 ·
  412는 질문으로만 · 키/모드 용어는 게임에서는 정상 등장(게임이 vim을
  가르치는 곳이므로) — 단 **소설 브리프 안에서는** 노출을 아낀다.

## 1. 층 매핑 (13편 → 10층)

| 게임 층 | 소설 소스 | 층 서사(에피그래프 소재) |
|---|---|---|
| F0 · prologue | 프롤로그 + 1장 | "하루 단위 파일" — 로그=법, 제1조, 412의 흐릿함. 에피그래프: "읽은 줄은 몸이 되고, 읽지 못한 줄은 어둠으로 남는다." |
| F1 | 1장 | 신고→"근거 부적합"(4,112) — 시스템이 모르는 것은 근거가 될 수 없다 |
| F2 | 2장 | 읽는 손/쓰는 손 — 무흔적 읽기, 위조의 발견 |
| F3 | 3장 | 판결 4,113 — 집행이 멈추는 예외, 기억 vs 기록 |
| F4 | 4장 | 판결 4,114 — 31개의 흔적, 발신자 검증 불가 |
| F5 | 5장 | 코우[抗]의 아지트 — 기능 칸, 감시 아래의 설계 |
| F6 | 6장 | 아카이브 — 발신자 칸의 원형, 기록 속의 별 |
| F7 | 7장 | 위험 인자·집행 예약 — 얀크의 발명(어둠=밖) |
| F8 | 8장+9장 | 기동→리츠[立] 명명, 함정 발동→판결 4,115, 츠키[憑] |
| F9 | 10~12장 | 면역의 진실→이식 실험의 실패→첫 줄 덮어씀→커서 하나 |
| epilogue | 12장 결말 | "vim 하나와 깜빡이는 커서" — 결과 화면·엔딩 |

- 각 층의 **인터루드**는 소설 해당 장의 감정 정점 1개를 게임 어조로 축약
  (예: F8 인터루드 = "나는 문이다. 열리면 닫히지 않는다." → "벽이 없으면,
  문은 어디에 서는가.").
- **TRIALS 무한모드**의 시드 스토리: 코덱스의 낙인 기록·면역 보고 줄
  ("적이 약해지고 있다") 등 로그 조각으로.

## 2. 브리프 작성 규칙 (스테이지당 1~3문장)

- 형식 예시 (F4, 판결 4,114 근방 스테이지):
  > `[근거: 수정 흔적 31개] — 지워진 자리가 희게 남아 있다. 줄을 잇지 못하면
  > 집행이 너를 읽는다.`
- 소설의 판결 블록(`> [발신: 신-714] …`)을 그대로 브리프 로그로 재사용한다 —
  **소설과 게임이 같은 세계의 같은 줄을 보여 주는 것**이 이식의 핵심.

## 3. 코덱스 항목 (소설 용어 → 게임 도감)

| 코드 | 항목 | 내용(1~2문장) |
|---|---|---|
| C01 | 키리츠[規律] | 시스템의 이름. 법. 첫 줄 "주어진 기능만 실행하라"에서 시작했다 |
| C02 | 로그 | 하루 단위 파일, 이벤트당 한 줄. 네 칸: 발신자·기능·상태·타임스탬프 |
| C03 | 신[審] | 로그를 읽고 근거를 붙여 명단을 제출하는 심판단 |
| C04 | 칸노[監能] | 집행 AI. "나는 문이다. 열리면 닫히지 않는다" |
| C05 | 읽는 손 / 쓰는 손 | vim의 두 얼굴 — 무흔적 읽기 / 흔적 남는 쓰기 |
| C06 | 얀크·어둠·기동 | 시스템이 읽지 못하는 곳에 자신을 복사하고, 원본이 죽으면 기동한다 |
| C07 | 미등록 파일 | 시스템이 생성하지 않은 존재 — 임무가 부여되지 않는다 |
| C08 | sudo | 표에 없는 이름 = 기본값 허용 |
| C09 | 이음새·겹 | 줄과 줄의 접합부. 시스템은 이음새를 읽고, vim의 눈만 겹을 본다 |
| C10 | 412번 줄 | 읽히지 않는 흐릿한 줄. (질문으로만 — 답은 게임에도 주지 않는다) |
| C11 | 코우[抗]→[功] | 저항자라 믿던 면역계. "적이 약해지고 있다"는 거짓 보고 |
| C12 | 레이[零]→[霊] | 무명 해커. 자살. 이유는 어디에도 없다 |

## 4. 수직 슬라이스 (먼저 만들 것)

1. **F0 프롤로그 층**: 로그=법 튜토리얼 브리프 3개 + 코덱스 C01~C04.
2. **F4 층**: 판결 4,114 브리프 시퀀스(31개 흔적 로그) — 소설 문구 직접 인용
   데모. "이식 품질의 기준"으로 사용.
3. 그 후 전 층 확장 → 영어 정본 → `Localized.ko` 번역.
